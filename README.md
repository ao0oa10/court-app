# نظام محاضر الجلسات الذكية

تطبيق عربي RTL محلي لصياغة محاضر الجلسات من خلال إجابات متسلسلة، مع معاينة مباشرة، أرشيف IndexedDB، نسخ احتياطي واستعادة، وتطبيق PWA قابل للعمل دون اتصال بعد تحميل الموارد.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة النشر:

```bash
npm run build
```

تُخدم مجلد `dist` عبر HTTPS عند النشر، ويمكن تثبيت التطبيق من Safari أو المتصفحات الداعمة بعد توفير manifest وملف الخدمة.

## الاختبارات

```bash
npm test
```

تشمل الاختبارات قواعد الغياب الجماعي، الحضور عن بُعد والتحقق من الهوية، الوكيل والطلبات المخصصة، والمثنى في حالتي الرفع والجر.

## ملاحظات الخصوصية والحدود

- لا تُرسل بيانات المحاضر إلى خدمات خارجية، والتخزين محلي داخل المتصفح.
- حذف بيانات المتصفح أو فقدان الجهاز قد يؤدي إلى فقدان المحاضر؛ استخدم النسخ الاحتياطي بانتظام.
- التصدير إلى Word يتم بصيغة HTML متوافقة مع Word، أما PDF فيتم عبر نافذة الطباعة واختيار «حفظ كملف PDF».
- تم اختبار البناء واختبارات الوحدات وتدفق الواجهة عبر متصفح آلي؛ لم يُجر اختبار على جهاز iPhone أو Safari حقيقي.
- الصياغة الناتجة حتمية مبنية على القوالب والإجابات، وتحتاج مراجعة المستخدم قبل اعتماد أي محضر قانوني.
